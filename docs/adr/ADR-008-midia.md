# ADR-008 — Mídia (planejado para G2)
**Estado:** Adotado como diretriz · implementação pendente

Upload retomável, checksum, validação de MIME real; derivados WebP/JPEG e miniatura gerados no worker; remoção de EXIF/GPS desnecessários; URLs assinadas e expirantes; volume persistente com backup, migrável para storage S3-compatível quando o volume justificar.
