# Rebania — assets da landing page

Abra `design/landing-desktop-revisada.png` para revisar a composição e `docs/GUIA_IMPLEMENTACAO.md` para implementar.

- `assets/`: três fotografias, logo e símbolo transparentes; logo anterior aprovada como referência de fidelidade.
- `design/`: prancheta, tokens CSS, textos definitivos e mapa de ícones Lucide.
- `reference/componentes.html`: exemplo local de componentes; abra no navegador. Não é a landing completa nem possui backend.
- `manifest.json`: dimensões nativas, transparência e checksums dos PNG.
- `docs/`: análise, instruções, prompt de implementação e prompts dos assets.

Textos, marca e componentes do pacote prevalecem sobre pequenas imprecisões de texto da imagem gerada. Cards, dispositivos e gráficos de interface devem ser construídos em HTML/CSS. Não recorte a prancheta para criar interfaces. As fotos são ilustrativas e os dados do exemplo são fictícios.

Não há fonte comercial nem pacote de ícones embutido: a interface usa fontes do sistema e o mapa aponta para componentes existentes da biblioteca Lucide. A marca usa o PNG fornecido. A validação visual automatizada permanece pendente por falta de Chromium neste ambiente.
